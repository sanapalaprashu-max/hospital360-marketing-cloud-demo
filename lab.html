Deployment & implementation order

1
Publish this site on GitHub Pages

Upload the files at repository root, then go to Settings → Pages → Deploy from a branch → main → /(root).

2
Use the existing webinar form

Click its website link. The form is hosted on CloudPages, not within GitHub Pages.

3
Build the hospital enquiry CloudPage

Create HSP_Enquiry_DE and an associated landing page; publish it and update config.js.

4
Configure Journey Builder & tracking

Use a supported sendable entry source, test data and an authorized sender to validate the full journey.
